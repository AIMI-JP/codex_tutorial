# Windows App

Windowsクライアント版（Tauri + TypeScript）の実装ディレクトリ。

## 方針
- 仕様は `docs/SPECIFICATION.md` を準拠とする。
- 実装はTDDで進める。

## セットアップ
詳細は `docs/WINDOWS_SETUP.md` を参照。

## コマンド
- 開発（Web側のみ）: `npm run dev:windows`
- テスト: `npm run test:windows`
- 型チェック: `npm run typecheck:windows`
- Tauri開発起動: `npm run tauri:dev:windows`
- Tauriビルド: `npm run tauri:build:windows`
