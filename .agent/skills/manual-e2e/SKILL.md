# 手動 E2E チェック（MVP 電卓）

## 前提
1. `npm install` 済み
2. `npm run dev` でアプリ起動
3. ブラウザで `http://127.0.0.1:5173/` を開く

## 主要シナリオ
1. `2 + 3 =` で `5`
2. `5 × 6 =` で `30`
3. `9 ÷ 0 =` で `Error`、`AC` 以外操作不可
4. `AC` で `0` に戻る
5. `1 . 2 . 3` で `1.23`
6. `12 + 3 = + 4 =` で `19`

## キーボードシナリオ
1. `4 * 5 Enter` で `20`（`* -> ×`）
2. `9 Escape` で `0`（`Escape -> AC`）
3. `123 Backspace` で `12`
