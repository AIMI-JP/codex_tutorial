# 電卓アプリ 実装タスク（TypeScript / TDD）

## 1. 方針
- 対象: MVP（`SPECIFICATION.md` 準拠）
- 実装技術: TypeScript + HTML + CSS
- 開発プロセス: すべての機能を TDD（Red -> Green -> Refactor）で実装
- テスト層:
  - 単体テスト: 計算ロジック、状態遷移
  - UI結合テスト: DOM更新、ボタン操作、キーボード操作
  - 手動受け入れテスト: 要件の受け入れ基準

## 2. TDD運用ルール
- [ ] R-1: 実装コードより先に失敗するテストを書く（Red）
- [ ] R-2: テストを通す最小実装のみ行う（Green）
- [ ] R-3: テストが通った状態でのみリファクタする（Refactor）
- [ ] R-4: 1タスクごとに `test` を再実行し、常にグリーン維持
- [ ] R-5: バグ修正は「再現テスト追加 -> 修正」の順で行う

完了条件:
- 追加された機能は必ず対応テストとセットになっている。
